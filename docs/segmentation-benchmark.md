# Segmentation benchmark

`segmentation_benchmark` runs multiple 3-D nuclei segmentation methods on the
same TIFF test set, saves every result as an instance-labeled TIFF, and compares
each result with a matching ground-truth mask.

Supported methods are:

- global Otsu thresholding with connected components;
- global Otsu thresholding followed by a 3-D distance-transform watershed;
- the repository's trained 3-D U-Net;
- Cellpose in 3-D mode;
- StarDist 3-D; and
- any externally generated masks, using the `--precomputed NAME=DIR` option.

## Install

Install the small, shared benchmark dependencies:

```bash
python -m pip install -r requirements-benchmark.txt
```

Only install dependencies for learned methods that will be run:

```bash
# Existing U-Net
python -m pip install torch

# Cellpose
python -m pip install cellpose

# StarDist (select the TensorFlow build appropriate for the machine)
python -m pip install stardist tensorflow
```

## Data layout

Input and ground-truth directories must contain matching relative TIFF paths.
Nested directories are supported, and `.tif` and `.tiff` are treated as
equivalent extensions.

```text
data/test/
├── raw/
│   ├── cortex/volume_01.tif
│   └── thalamus/volume_02.tif
└── ground_truth/
    ├── cortex/volume_01.tif
    └── thalamus/volume_02.tif
```

Volumes must be 3-D `(Z, Y, X)` TIFFs. A 4-D input is also accepted when its
channel is selected with `--channel` and `--channel-axis`. Masks must be 3-D.

Ground truth may be:

- **binary**, including Ilastik-derived `0/1` or `0/255` masks; or
- **instance-labeled**, with `0` as background and one positive integer per
  nucleus.

The default `--ground-truth-mode auto` detects two-valued masks as binary and
otherwise expects integer instance labels. Binary masks are converted to
face-connected components. Use instance-labeled ground truth when touching
nuclei must remain separate for object-level scoring.

## Run

Run the two lightweight baselines:

```bash
python -m segmentation_benchmark \
  --input-dir data/test/raw \
  --ground-truth-dir data/test/ground_truth \
  --output-dir benchmark-runs/otsu-baselines \
  --methods otsu otsu-watershed \
  --voxel-size 1.34 1.54 2.0 \
  --min-size 20 \
  --watershed-min-distance 3
```

Run all integrated methods:

```bash
python -m segmentation_benchmark \
  --input-dir data/test/raw \
  --ground-truth-dir data/test/ground_truth \
  --output-dir benchmark-runs/all-methods \
  --methods otsu otsu-watershed unet cellpose stardist \
  --voxel-size 1.34 1.54 2.0 \
  --unet-model models/unet_best.pth \
  --unet-layers 3 \
  --unet-patch-size 128 \
  --cellpose-model nuclei \
  --stardist-model 3D_demo
```

Custom trained models can be selected with `--cellpose-model-path` and
`--stardist-model-path`. The StarDist path must be a model directory containing
its config and weights. Run `python -m segmentation_benchmark --help` for all
threshold, model, device, and channel options.

To compare masks generated by a method outside this runner, point to a
directory with the same relative layout:

```bash
python -m segmentation_benchmark \
  --input-dir data/test/raw \
  --ground-truth-dir data/test/ground_truth \
  --output-dir benchmark-runs/with-existing-masks \
  --methods otsu otsu-watershed \
  --precomputed unet=/path/to/unet/masks \
  --precomputed alternate_ilastik=/path/to/alternate/masks
```

Precomputed masks are evaluated and copied into the run directory, but their
runtime is blank because segmentation did not execute in the benchmark process.
For a precomputed-only run, pass `--methods` with no method names before the
first `--precomputed` option.
The output directory must be new or empty so results from separate runs cannot
be mixed accidentally.

## Outputs

Each run is self-contained:

```text
benchmark-runs/all-methods/
├── manifest.json
├── summary.md
├── masks/
│   ├── ground_truth/
│   ├── otsu/
│   ├── otsu-watershed/
│   ├── unet/
│   ├── cellpose/
│   └── stardist/
└── metrics/
    ├── by_method.csv
    ├── by_volume.csv
    └── by_object.csv
```

All stored masks are instance-labeled TIFFs. `by_object.csv` contains the voxel
count, physical volume, equivalent-sphere diameter, centroid, bounding box, and
best/matched ground-truth object for every predicted mask. It also includes
ground-truth object measurements under the `ground_truth` method name. Physical
measurements are populated only when `--voxel-size Z Y X` is supplied.

`by_volume.csv` contains runtime, object counts, count error, foreground size,
semantic Dice/IoU, object precision/recall/F1, mean matched IoU, and panoptic
quality for every volume and method. `by_method.csv` aggregates those results.
`manifest.json` records the command, inputs, options, platform, and one-time
model setup times, along with installed package versions.

Per-volume runtime covers segmentation inference only. It intentionally
excludes common TIFF reads, output writes, and metric calculation. Model
construction and weight loading are timed separately; GPU work is synchronized
at timing boundaries. `setup_plus_inference_seconds` in `by_method.csv` reports
their combined time. Object detections are matched one-to-one, in descending
pairwise IoU order, using an IoU threshold of `0.5` by default.
